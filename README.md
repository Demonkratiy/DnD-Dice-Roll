# 🎲 DnD Dice Roller

Веб-приложение для броска кубиков Dungeons & Dragons (d4–d100) с акцентом на
**эмоции и стиль**: тактильный бросок жестом по кубику, приятные анимации перебора
форм и аккуратный минималистичный интерфейс.

> Учебный проект — фокус на чистой архитектуре, читаемости и документации.

## ✨ Возможности (в разработке)

- Бросок жестом по кубику: тап — бросок, зажать — «тряска», отпустить — перебор форм.
- Набор кубиков: d4, d6, d8, d10, d12, d20, d100.
- Несколько кубиков за бросок (например, 3d6), модификаторы `+/−`.
- Режим Advantage / Disadvantage для d20.
- Переключаемые темы оформления.
- Опциональный лог бросков (выезжающая снизу панель).

Задел на будущее: звуки, тематические силуэты, мультиплеер (совместные игры с ГМ).

## 🚀 Запуск

```bash
npm install      # установить зависимости
npm run dev      # запустить дев-сервер
```

Откройте адрес, который выведет Vite (обычно http://localhost:5173).

## 🏗️ Архитектура

Проект следует **FSD-lite** (облегчённый Feature-Sliced Design). Импорты направлены
только вниз: `app → features → entities → shared`.

```
src/
  app/         точка входа, App, провайдеры, глобальные стили
  features/    сценарии и блоки UI: stage, dice-picker, roll-controls, settings, log
  entities/    бизнес-сущности: die, roll, player (типы + чистая логика)
  shared/      ui-kit, утилиты/хуки, сервисы, темы, конфиг
```

Подробности видения и архитектурные принципы — в [AGENTS.md](./AGENTS.md).
Технические разборы «как что реализовано» — в [dev-wiki/](./dev-wiki/README.md).
